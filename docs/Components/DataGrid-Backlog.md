# VekDataGrid Backlog: 40 Tasks

این فهرست، پیشنهاد کارهای بعدی برای نزدیک‌ترکردن تجربهٔ VekDataGrid به gridهای کامل سازمانی است. موارد را به‌ترتیب اولویت پیشنهادی نوشته‌ام؛ پیش از شروع هر مورد، وضعیت فعلی کد و نمونه‌ها بررسی شود تا قابلیت موجود دوباره‌کاری نشود.

برای قابلیت‌های مشترک، قرارداد و رفتار در `Vek.Core.DataGrid` قرار می‌گیرد و هر دو adapter یعنی Blazor و WPF باید همان رفتار را ارائه دهند. قابلیت‌های وابسته به UI، clipboard یا فایل خروجی می‌توانند در adapter بمانند. برای هر تغییر، رفتار قابل مشاهده در هر دو adapter که پشتیبانی می‌شوند آزمون شود.
