# WPF Demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a native WPF demo with the same 20 screens and navigation structure as the Blazor demo, using shared product data and incremental WPF samples.

**Architecture:** `Vek.WPF.Demo` is the composition root. It references the reusable WPF DataGrid library plus the shared demo ports and JSON adapter. A page catalog drives a single-window Home and documentation shell; native WPF controls render the examples.

**Tech Stack:** .NET 10 WPF, C#, XAML, xUnit.

**Spec:** `docs/superpowers/specs/2026-10-30-wpf-demo-design.md`

## Global Constraints

- All projects target .NET 10; the WPF app and WPF controls target `net10.0-windows`.
- Keep reusable WPF controls independent of Demo and sample-data projects.
- The WPF Demo is the composition root for component, demo-port, and sample-data dependencies.
- Preserve all 20 current screens and show incomplete DataGrid features as in development.
- Mirror the Blazor documentation sidebar hierarchy, per-page title/introduction, ordered sections, and local table of contents; keep Home outside the docs sidebar.
- Mirror `Components/Pages/Docs/Blazor` with same-named WPF XAML pages under `src/Demo/WPF/Vek.WPF.Demo/Components/Pages/Docs/WPF`; keep Home at `Components/Pages/Home.xaml` and the docs shell under `Components/Layout`.
- Keep VekCodeView Basic Usage as four ordered sections (HTML, Java, C#, SQL); keep Multi-Sample as one selectable-sample section.
- Every C# `[Fact]` or `[Theory]` has an XML summary immediately above the attribute.

## Review Focus

- Home starts first and navigation swaps content in a single window.
- The catalog contains each current screen exactly once: Home, Getting Started, 16 DataGrid topics, and two CodeView topics.
- Incomplete DataGrid topics are clearly marked and do not claim live behavior.
- The basic sample loads products through `IDemoProductProvider`.
- Code samples are read-only, keyboard-focusable, and selectable.
- Every documentation page's local table of contents links to its rendered sections in the same order as the Blazor source.
- Each destination loads its own full XAML `UserControl` in the right pane while the shell and left navigation remain mounted.
- Each page XAML contains its own article and TOC layout; no shared generic view constructs the page content at runtime.
- Basic Usage renders a native `VekDataGrid` with Name, Category, Price, and Product ID columns.
